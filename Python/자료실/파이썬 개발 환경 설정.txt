< 파이썬 개발 환경 설정 >

1. Python 3.14.5 다운/설치/확인
   (1) https://www.python.org/downloads/windows/
      'Stable Releases' > 'python-3.14.5-amd64.exe' 다운 실행
   (2) 파일실행 > 하단의 'Add python.exe to PATH'체크 > 'Install Now'클릭
   (3) 설치버전확인( CMD or PS 에서 )
      C:\Users\user>python --version //Python 3.14.5
       '또는'
      C:\Users\user>python -V //Python 3.14.5
   (4) 테스트
      C:\Users\user>python
      >>> print('Hello Python')
      //Hello Python
   
2. VSCode
   (1) https://code.visualstudio.com/download
      > 'VSCodeUserSetup-x64-1.119.0.exe' 다운/실행
   (2) 작업 디렉토리 생성/열기
      C:\SOO\Python\day01 > File 의 Open Folder..
   (3) hello.py 생성
      print('안녕 파이썬')
   (4) 실행
      1) VSCode 터미널
         - py hello.py 또는 python hello.py
         - Extension Pack: 'Python'검색 > 우측상단의 '실행'버튼
      2) CMD or PS 에서
         - py hello.py 또는 python hello.py
   (5) 폰트사이즈 변경
      1) 코드 패널
         Ctrl+, > 'font' > 30
      2) 터미널 패널( '송현화' )
         Ctrl+, > 'terminal font size' > 32

3. 가상환경
   (1) 가상환경 생성

   (2) 활성화/비활성화

      2) PS

            PS C:\> get-Ex
			
			ecutionPolicy //RemoteSigned 변경확인
