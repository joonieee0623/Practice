어떤 '일'을 수행하는 기능으로써 주어진 인수(argument)를 재료로 '처리'하여, 그 결과를 'return'하는 일

<기능에 따른 분류>
1) Data 계산
2) Data 변환

<행에 따른 분류>
1) 단일행 함수(ex: nvl,..)
	-> 하나의 행(row)당, 하나의 결과값을 리턴하는 함수
2) 복수행 함수(ex : max, min, avg,..)
	-> 여러개의 행(row)당, 하나의 결과값을 리턴하는 함수

3. 날짜 함수
db에서밖에 처리할 수 없어 중요
1) sysdate 또는 now
select sysdate();

now 오라클엔 없음

2) date__add 날짜 자동 계산
select hiredate from emp where empno=7782;
select hiredate, date_add(hiredate, interval 7 month)from emp where empno=7782;
	select hiredate다음에 , -> 비교해서 출력

3) last_day
select str_to_date('26/8/05', '%y/%m/%d');
select last_day(str_to_date('26/8/05', '%y/%m/%d')); -- 2026-08-31
select hiredate, last_day(hiredate) from emp;
