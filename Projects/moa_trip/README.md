# 🧳 모아트립 (moa_trip)

공공데이터(한국관광공사·기상청) 기반 **여행 일정 및 관광 정보 공유 플랫폼** — Django 팀 프로젝트

- **기간** : `2026.09.10` ~ `2026.09.22`
- **인원** : 4명 (팀 SOO-Team2)
- **팀 저장소** : [SOO-Team2/moa_trip](https://github.com/SOO-Team2/moa_trip)

---

## 🛠 기술 스택

| 구분 | 사용 기술 |
|---|---|
| Backend | Python, Django 4.2 |
| Database | MariaDB (mysqlclient) |
| Frontend | HTML, CSS, JavaScript (Django Template) |
| 외부 API | 한국관광공사 TourAPI (국문 관광정보 / 반려동물 동반여행), 기상청 단기·중기예보, 네이버 지도 API |
| 협업 | Git / GitHub (feature 브랜치 → PR → master) |

---

## ✨ 주요 기능

- **메인** : 추천 관광지(랜덤 정렬), 반려동물 동반 관광지
- **관광지 탐색** : 지역·반려동물·평점 필터, 후기순 등 정렬
- **관광지 상세** : 관광지 정보·이미지 갤러리, 날씨 예보, 후기 작성/삭제, 즐겨찾기
- **여행 일정 플래너** : 일정 생성, 장소 추가/삭제, 방문 시간 지정, 즐겨찾기에서 바로 추가
- **마이페이지** : 대시보드, 즐겨찾기·후기 목록 (최신순)
- **회원** : 회원가입(비밀번호 해싱), 로그인/로그아웃
- **관리자 페이지**

---

## 🗄 DB 구조

```
USERS ─┬─< FAVORITE >─┐
       ├─< REVIEW   >─┼── TOURISTSPOT >── REGION
       └─< ITINERARY ─< ITINERARY_TIME >─┘
```

| 테이블 | 설명 |
|---|---|
| USERS | 회원 |
| REGION | 지역 코드 |
| TOURISTSPOT | 관광지 (TourAPI 데이터) |
| FAVORITE | 회원 ↔ 관광지 즐겨찾기 |
| REVIEW | 관광지 후기 (별점, 사진) |
| ITINERARY | 여행 일정 |
| ITINERARY_TIME | 일정별 방문 장소·시간 (1:N) |

---

## 🙋 내가 맡은 부분

**화면 (Template / CSS)**
- 공통 레이아웃 : `base.html`, 헤더
- 메인, 로그인, 탐색, 마이페이지, 관리자 페이지 화면 구성
- 로그인 ↔ 회원가입 탭을 화면 전환 없이 전환

**기능 (View / Model)**
- 회원가입 : 비밀번호 해싱, 가입일자 저장
- 탐색 페이지 : 지역·반려동물·평점 필터, 후기순 정렬
- 즐겨찾기 : 탐색 페이지에서 추가, 플래너와 연동
- 여행 일정 플래너 : 장소 추가/삭제, 방문 시간 추가 (`ITINERARY_TIME` 1:N 구조 반영)
- 후기 : 별점 UI와 DB 저장 로직 통합, 메인/탐색 페이지 평점·후기 수를 실제 데이터로 표시
- 상세 페이지 : 이미지 확대 팝업 + 화살표로 넘기기
- 마이페이지 : 대시보드, 즐겨찾기/후기 최신순 정렬

## 🔧 트러블슈팅

| 문제 | 해결 |
|---|---|
| 일정 저장 시 같은 일정이 중복 생성됨 | 저장 로직을 수정하고 일정 삭제 API를 하나로 통합 |
| 상세 페이지 사이드바 레이아웃이 깨짐 | 후기 목록의 `div` 태그 짝이 맞지 않던 부분 수정 |
| `onclick` 안의 `{% url %}` 태그가 동작하지 않음 | HTML 속성 따옴표와 템플릿 태그 따옴표가 충돌 → 따옴표 종류를 구분 |
| 탐색 페이지 평점 필터·후기순 정렬이 적용되지 않음 | View의 필터/정렬 쿼리 수정 |
| 평점·후기 수가 하드코딩된 샘플 값으로 표시됨 | 샘플 데이터를 제거하고 실제 `REVIEW` 데이터로 집계 |
| 후기 등록 후 모달이 닫히지 않고, 마이페이지에 사진이 안 보임 | 모달 종료 처리와 이미지 경로 수정 |
